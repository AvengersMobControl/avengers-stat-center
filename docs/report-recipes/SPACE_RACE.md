# Recipe 3 — Space Race PNG and Discord message

## Scope and website pull

One event, one event-time clan report: AVENGERS and AV-2 separately. Select exact canonical space|YYYY-MM-DD and source-backed lobby/arena identifiers from the accepted versioned public projection and event-summary exports. For historical placement distinctions use space-rank-history.js analyze() and the existing approved Space template in scripts/render-space-summary.py. The current Space renderer has a historical hardcoded October 16 date and other fixed prior-date text; a future automatic adapter MUST remove those constants and take display dates/comparisons entirely from the selected website event. Do not silently restyle the approved Space image.

Accept complete original verified final screenshot coverage for unattended posting; independent clan cohort evidence matters. A marked-final event alone does NOT prove all lobbies: an all-clan finish rank is VERIFIED only when event.metadata.verifiedAllLobbyClans[clan] is true, consistent with space-rank-history.js. Missing clan-wide coverage may still allow an accurate partial website update, not an automatic full-clan PNG.

## Frozen field checklist, in priority order

1. Event-time clan, date, participating source-identified players, actual lobbies, known result rows, coverage and comparison against the previous same-clan accepted Space event.
2. Four headline blocks modeled on the approved Space design: TOTAL DISTANCE, AVERAGE DISTANCE PER PARTICIPANT, CLAN-KNOWN STARS, PARTICIPANTS / KNOWN SPARKS. Distance is in billions of lightyears (e.g. 500.9B), with consistent rounding only for display; retain exact numeric values for totals, PBs and consistency checks. Show total/average change only if prior event sample and definitions are comparable.
3. Top participants by distance with canonical identity, exact individual result, source lobby and source rank where verified. Maintain separate classifications: source-observed LOBBY FINISH, recorded-clan rank among captured rows, and VERIFIED all-clan finish rank (only when independently attested). Never call a distance-sort a game-place medal.
4. Distance PBs and record improvements from website histories: previous distance, new distance, prior exact date, percent increase, new/tied records. Distinguish first tracked Space appearance from a returning-player PB.
5. Exact source-backed Stars/Sparks rewards. Stars that came from the authorized exact Sparks×10 derivation must be labeled derived; preserve directly observed conflicting Stars and log ratio mismatch rather than silently fixing it. Unknowns stay unknown. Whole lobby Star pot is distinct from clan-earned Stars.
6. Sparks per BILLION lightyears is a SPACE EVENT TABLE secondary metric only, where both earned Sparks and positive distance are known. It may be used in a weekly recognition graphic, but must NOT proliferate to roster, Space Overall, member profiles or other reports. Do not use Sparks/line terminology for Space.
7. Meaningful extras only when sourced: head-to-head distances, new all-time distances, tracked event records, minimum-clan benchmarks (30B usual; Sept 27 2026 was 50B), relative prior achievements. Omit unverified or trivial claims. No fabricated country flags, medals or unverified game achievements.

## Compile the detailed visual prompt

Preserve the existing 2400×1500 Space navy/cyan/purple design and statistical priority, original orbit graphics and practical legibility. Approved original Spider/Explodon, Terrorist, Kaboom/Pirate and Raccoon/Rocket files are the primary Space character palette; verify SHA-256 against docs/APPROVED_CHARACTER_ASSETS.md. Character assets decorate around, never cover data. Fact pack provides every date, unit, PB, source rank and reward label. Decorative generation is allowed behind data fields, but exact text and numerals are inserted mechanically. Layout must grow when PB list or tracked first appearances exceed the old renderer's fixed slot count.

Example prompt: "Produce a high-contrast Space Race results art composition matching the approved navy/cyan/purple poster. Use referenced original Space characters as framing elements, with unobstructed variable-height slots for four KPI boxes, verified lobby/rank table, PB transitions and new tracked members. No generated numbers, distances, dates, medallions or player names."

## Discord message compiler

Recap recorded total and per-player average distance, top verified distance contributors, clearly attested personal records, major comparable improvement, known clan Sparks/Stars, and recognition of members surpassing prior averages if source comparators exist. Use friendly, competitive clan voice, not empty motivation slogans or unverified superlatives. Provide the site link, distinguish sample coverage from complete event when necessary and never assert all-clan ranks from a partial screenshot.

## Hard-stop checklist

Preliminary Space scoreboard, crossed AVENGERS/AV-2 data, ambiguous decimal units, unproven all-clan placing, unknown cropped lobby called complete, computed derived payout passed off as screenshot-exact, stale October 16 date in renderer, false PB baseline or partial image clipping. Under these conditions retain review-only art and require correction. Existing art: scripts/render-space-summary.py. Auto Discord posting remains OFF.
